# Hospital Management Backend

Backend scaffold built with Node.js, Express, TypeScript, and Zod.

## Stack

- Controller / service / repository separation
- DTO validation with Zod
- Request logging middleware
- Global error handling
- In-memory repositories for easy replacement with a database later

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm start`
